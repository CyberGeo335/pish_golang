#### INFO:
REST (Representational State Transfer) — это архитектурный стиль взаимодействия клиентских и серверных приложений через 
протокол HTTP
CRUD:
![Скриншот запуска](./assets/Снимок%20экрана%202025-12-07%20в%2020.43.58.png)

Коды ответов:
* 200 — успешное выполнение;
* 201 — создан новый ресурс;
* 204 — операция выполнена, контент не возвращается;
* 400 — некорректный запрос;
* 404 — ресурс не найден;
* 500 — внутренняя ошибка сервера.
